# 理财指数评估

## 公式

> **理财指数 = 10 × 家庭净资产 / (平均年龄 × 年工资收入)**

### 计算步骤

1. **家庭净资产** = 总资产 - 总债务
   - 总资产：金融资产（存款、基金、债券）+ 非金融资产（房产、汽车等）
   - 总债务：房贷、车贷、信用卡债等

2. **年工资收入**：仅计算劳动收入，不含被动收入（利息、分红、房租等）

3. **平均年龄**：家庭成员年龄的平均值

## 评级标准

| 理财指数 | 评级 | 说明 |
|---------|------|------|
| < 0.5 | ⚠️ 不及格 | 需要大幅改善理财习惯 |
| 0.5 - 1.0 | 🔶 接近及格 | 还需努力 |
| 1.0 - 1.5 | ✅ 及格 | 良好的理财水平 |
| 1.5 - 2.0 | ⭐ 优秀 | 超过大部分家庭 |
| 2.0 - 3.0 | 🏆 卓越 | 顶级水平 |
| > 3.0 | 👑 极致 | 万里挑一 |

### 极端案例

- **马斯克**（52岁）：10 × 2200亿 / (52 × 2.45亿) = **173**
- **巴菲特**（93岁）：10 × 1100亿 / (93 × 10万) = **1,182,800**
- **门卫 Ronald Read**（退休工资几万美元，去世时股票账户 800 万）：**30+**

## 如何提高理财指数

1. **提高储蓄率**：开源节流，省下的每一元等于多挣一元
2. **提高投资收益率**：从银行存款/保险 → 指数基金
3. **尽早开始**：复利需要时间，越早越好

## 注意事项

- 参加工作不足 5 年的家庭不适用此公式
- 继承或赠与的资产应从净资产中扣除
- 仅适用于工资收入，不含被动收入
