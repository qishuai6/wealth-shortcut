# 4% 取钱法则

## 基本原理

> 你可以从投资组合中每年安全取出一定比例的资金，而不会耗尽资产。
> 安全取款率 = 年化收益率 - 通胀率

## 不同组合的安全取款率

| 投资组合 | 年化收益率 | 安全取款率 | 100万每年可取 |
|---------|-----------|-----------|-------------|
| 100% 银行存款 | 2-4% | ~0-1% | 0-1 万 |
| 80% 债券 + 20% 股票 | 5-6% | ~2-3% | 2-3 万 |
| 60% 债券 + 40% 股票（传统） | 7% | ~4% | 4 万 |
| 90% 股票 + 10% 债券（巴菲特推荐） | 9.5% | ~6.5% | 6.5 万 |
| 100% 股票指数基金 | 10-11% | ~7% | 7 万 |

## 历史验证

Javier Estrada 2015 年论文研究了 1900-1985 年的 86 个 30 年窗口期：

| 资产配置(股/债) | 失败率 | 评价 |
|---------------|--------|------|
| 100/0 | 3.5% | 可接受 |
| 90/10 | 2.3% | ✅ 推荐 |
| 80/20 | 2.3% | ✅ 推荐 |
| 70/30 | 1.2% | ✅ 推荐 |
| 60/40 | 0% | 最安全但收益低 |
| 40/60 | 3.5% | 不推荐 |
| 30/70 | 12.8% | ❌ 高失败率 |

**关键结论**：
- 90/10 方案失败率仅 2.3%，但平均剩余资产比 60/40 高 **108%**
- 债券超过 70% 时，失败率急剧上升
- 退休人士必须持有足够的股票

## 退休取钱策略（美国用户）

### 第一阶段：领取社安金之前（64-67/70 岁）

1. 优先从**普通应税账户**取钱
2. 同时从 401k/IRA 转 5 万到 Roth IRA（利用低税率窗口）
3. 让退休金账户资金继续增长

### 第二阶段：领取社安金之后

1. 社安金 + 应税账户取款
2. 继续利用低税率窗口做 Roth 转换

### 第三阶段：RMD 开始后（73/75 岁）

1. 优先满足 RMD 要求
2. 多余资金可转入普通账户继续投资
3. 不足部分从应税账户补充

## 财务自由公式

> **金融资产 × 4% + 房租 + 其它被动收入 >= 家庭年开支**

### 快速计算

需要多少金融资产才能财务自由？

```
所需资产 = 年开支 × 25
```

| 年开支 | 所需金融资产（4%法则） |
|--------|---------------------|
| 5 万 | 125 万 |
| 10 万 | 250 万 |
| 15 万 | 375 万 |
| 20 万 | 500 万 |
| 30 万 | 750 万 |
| 50 万 | 1250 万 |

注意：如果有房租、退休金等其它被动收入，可以从年开支中扣除。
