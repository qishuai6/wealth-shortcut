# 投资产品推荐

## 推荐投资产品

### ✅ 指数基金（唯一推荐的投资产品）

指数基金的核心优势：
- 自动优胜劣汰：表现差的公司被剔除，后起之秀取代
- 从未有大盘指数基金破产或停止运营
- 90% 的主动基金 30 年内关门大吉
- 超额回报由最优秀的 20% 公司创造（二八定律）

## 新手如何选择：标普 vs 纳指

| 人群 | 建议 |
|------|------|
| 投资新手 | 以标普 500 为主，可一只基金走天下 |
| 看好科技未来 | 标普 500 + 纳斯达克 100，纳指不超过 50% |
| 经验丰富、心理素质强 | 可适当增大纳斯达克 100 比例 |

## 标普 vs 纳指的关键区别

| 维度 | 标普 500 | 纳斯达克 100 |
|------|---------|-------------|
| 成立年份 | 1957 | 1985 |
| 成分股 | 500 家（仅美国公司） | 100 家（含外国公司） |
| 科技占比 | 28% | 65% |
| 板块覆盖 | 全板块 | 缺金融、能源 |
| 过去 10 年年化 | ~13% | ~19% |
| 波动性 | 较低 | 较高 |
| 适合人群 | 稳健型 | 进取型 |

## ❌ 不推荐的产品

| 产品 | 年化收益率 | 不推荐原因 |
|------|-----------|-----------|
| 银行理财产品 | ~4% | 跑不赢通胀 |
| 封闭期产品 | 不定 | 流动性差 |
| 终身寿险/万能险 | ~3% | 收益低，流动性极差 |
| 加密货币/外汇 | 不确定 | 投机产品，无长期价值 |
| 黄金/白银 | ~6% | 远低于股市 |
| 个股 | 不确定 | 80% 跑输通胀，有破产风险 |
| 收藏品 | ~2% | 持有成本高，流动性差 |
| 银行定期存款 | ~3% | 跑不赢通胀 |
| 3倍杠杆ETF | 不确定 | 衰变严重，长期趋零 |

## 风险提示

> 在开始任何高风险的投资（房地产、股市）之前，家庭要准备足够应付半年到一年的基本支出的紧急储备金。这些储备金必须存在低风险的地方，比如银行存款、政府债券。
